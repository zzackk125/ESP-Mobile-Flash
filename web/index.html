ESP Mobile Flash

This browser can't reach USB. Firefox and Safari don't support Web Serial or WebUSB. Open this page in Chrome to flash over USB. Wi-Fi (OTA) updates and downloads still work here.

Settings

Firmware is read from your private repos with a GitHub fine-grained token: Repository access → your ESP repos (or all), Permissions → Contents: Read-only. It is stored only in this browser.

      Troubleshooting
      
      
        
    • Use a USB-C data cable (or OTG adapter) on the board's USB port (native USB), not the UART port.
      • 
        
    • If connecting fails: hold BOOT, tap RESET, release BOOT, then try again.
      • 
        
    • Boards with CP210x/FTDI chips only work via Web Serial (desktop Chrome). CH340 and native USB work on Android.
      • 
        
    • After flashing, a native-USB board restarts and reconnects — open the serial monitor again if needed.
      •
